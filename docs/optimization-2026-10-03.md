# 指令库体验优化记录

数据库分类已写入线上 Firestore：46 条，10 条直接试用、16 条需要文本、20 条需要外部环境。公开页面当前只显示公开且已发布的条目。备份位于被 Git 忽略的 `.local-backups/`。

## 本次代码优化

- 首页按管理员加星及创建时间选取最多三条推荐，搜索结果按匹配相关度显示。卡片明确说明输入、输出、使用条件，外部环境条目提供复制和 Agent 使用指南。
- 指令库支持组合关键词，名称和标签优先；查询与使用条件写入 URL，刷新及浏览器导航后可恢复。增加加载提示与实时连接失败的缓存说明。
- 首页取消 30 秒重复轮询，保留实时订阅。实时订阅失败会通知页面。
- 免费试用预算为平台保守策略：8192 总预算，预留 2048 输出、512 安全余量，输入指令与历史共 5632 估算 tokens。UTF-8 估算不是模型的精确 tokenizer，也不是宣称模型仅支持 8192。单次字符上限随指令长度降低，最高 2000，最多五轮共享模型体验。超限不静默截断。
- 流式客户端检查完成元数据，处理跨包字符、尾部错误、响应格式异常、提前断流和空输出。失败保留输入，恢复输入操作不自动追加重复消息。支持停止当前客户端请求，换页清理请求；中断输出标记不完整。停止客户端请求不保证上游立即停止推理。
- 成功生成与本地记录保存分别处理，记录保存失败不会把成功结果误报为生成失败。中文输入法组合键不会触发 Enter 发送。
- 登录弹窗加入 dialog 语义、焦点循环和关闭后焦点恢复；展示登录失败，登录成功后继续所选指令。
- 管理员发布前检查指令内容、输入/输出说明、使用条件、示例和上下文预算。
- 路由按需加载，增加加载状态、404、页面错误恢复。Firebase 初始化不依赖本地 IndexedDB 必须成功。
- 本地图标只打包实际使用的 73 个，新增图标会在 predev/prebuild 自动重新生成。

## 验证

- `npm run test:trial`：推荐排序、分类禁止试用、输入要求、上下文预算、46 条分类元数据，以及 SSE 中断/错误/拆包和检索相关度。
- `npx tsc -b`、`npm run lint`、`npx vite build`、`git diff --check`。
- 浏览器验证：移动端与桌面首页、URL 使用条件切换、登录弹窗关闭及焦点恢复、长输入在发送前被拦截。
- 主入口 JS 从前一版约 2067 KB（gzip 576 KB）减至约 779 KB（gzip 250 KB）；另有共享和页面按需加载文件。构建仍提示主包超过 500 KB，主要共享依赖尚可继续拆分。该指标不代表实际网络加载耗时。

本次代码尚未部署到正式网站。没有使用本地平台凭证执行真实模型生成，也没有完成管理员登录后的在线保存端到端验证；上述验证包括本地逻辑、模拟流响应及真实公开 Firestore 页面读取。
