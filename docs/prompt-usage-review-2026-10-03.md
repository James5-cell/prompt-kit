## 免费模型与上下文策略

线上公开配置读取到：NVIDIA `meta/llama-3.2-11b-vision-instruct`。下述为平台轻量体验预算，不是该模型的上下文上限：

- 总预算 8192 tokens；预留输出 2048、安全余量 512，输入（指令、正文、历史）最多估算 5632。
- UTF-8 字节数 / 2 为保守估算，不是精确 tokenizer 计数；页面明确标注估算。
- 输入最多 2000 字符，长指令按剩余预算下调。完整资料建议到其他 Agent 使用。
- 超出预算时拒绝调用并提示缩短或重新开始；不静默截断原文或历史。
- 共享平台模型最多 5 轮；个人 API Key 不受 5 轮限制，仍遵守轻量文本预算。
- 前后端都检查使用条件与输入预算；外部环境类不提供在线试用。
