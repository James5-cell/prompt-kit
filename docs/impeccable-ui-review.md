# Prompt Kit 界面检查

2026-10-29。检查范围：公共导航、首页、指令库、指令详情、试用、设置及管理界面；结合源码、现有页面截图与 Impeccable 源码扫描。现有截图可能早于当前界面，不作为当前渲染结果的证明。

## 优先发现

1. **搜索与分类不一致**：首页原先选择分类会清空搜索，而指令库允许组合筛选。已调整为组合筛选，进入指令库时保留两个条件，空结果说明如何扩大范围。
2. **手机端管理员导航**：五个入口放在四列网格中，最后一项会换行。已按权限设置列数；仍需在真实管理员账号下确认布局。
3. **视觉噪声**：全局链接发光、卡片浮动与模糊、重复的首页标题标签及弹跳动效让工具界面显得忙碌。已收敛这些效果，保留深色基底和青色交互提示。
4. **阅读和键盘操作**：全局辅助文字偏暗，部分元素依赖局部焦点样式。已提高辅助色亮度并提供全局键盘焦点提示；各页面硬编码颜色仍需逐一核对。
5. **设计系统一致性**：设置、详情、编辑和管理页面混用局部颜色、字号和组件样式。后续应按实际使用频率逐页整理，优先检查表单错误、长文本、窄屏及减弱动态效果；不要仅凭自动检测结果批量替换。

## 自动扫描

初次 `impeccable detect src/` 报告 4 项：Inter 字体、登录弹窗弹跳缓动、指令库复制成功图标弹跳、试用结果引用块左侧强调线。前三项已处理；引用块为内容语义而非卡片装饰，暂保留。源码扫描不能验证实际对比度、真实设备触控、登录状态或网络异常。

## 保留的优点

- 指令卡片区分可试用和需外部环境，用户在操作前能了解条件。
- 指令库把筛选条件写入 URL，便于返回和分享。
- 页面已有加载、空结果和失败反馈，后续调整应保留这些状态。

## 第二轮：设置与编辑流程

- 设置页的密钥输入改为遮蔽；配置状态现在反映已保存的密钥，而不是尚未保存的输入。连接失败提示也明确建议检查密钥和网络。
- 编辑器统一主要中文文案，增加加载失败和找不到指令时的返回入口，保存失败改为页内反馈；手机操作栏回到文档流，避免遮挡内容。状态按钮公开选中状态，输入控件焦点更清晰。
- 详情页统一正文、示例及登录提示的语言。
- 浏览器检查覆盖访客视角的窄屏设置、编辑及详情页；尚未使用管理员账号实际保存或连接真实 API 服务商。
